# YamaDeck

**Ваш ресивер Yamaha — в одной вкладке браузера.**

[English](README.md) · Русский

Веб-пульт для сетевых ресиверов Yamaha, разработанный и проверенный на **RX-V575**. Управляйте ресивером, просматривайте медиатеку DLNA, настраивайте радио и выбирайте источники для главной панели. Приложение работает в Docker на компьютере или NAS в домашней сети.

На сервере — стандартная библиотека Python; в браузере — обычные HTML, CSS и JavaScript. Для запуска не нужны npm-сборка или облачная учётная запись. Интерфейс сейчас на русском языке.

## Возможности

| Раздел | Управление |
| --- | --- |
| Питание и громкость | Основная зона, mute, ползунок, ±1 dB; пресеты −75, −60, −45, −30 и −15 dB. |
| Источники и сцены | Входы и четыре сцены ресивера; скрытие ненужных источников в настройках. |
| Звук | Программы DSP, Straight, Enhancer, Direct, Adaptive DRC, низкие и высокие частоты. |
| SERVER / DLNA | Серверы, папки и треки; переход назад и к серверам; play/pause/stop, предыдущий/следующий трек, повтор, случайный порядок, песня/исполнитель/альбом. |
| Радио | FM/AM, ввод частоты и настройка по шагам, автопоиск и остановка, сохранённые станции и переключение пресетов. |
| RDS | Названия станций, радиотекст, сигнал и стерео; полученные названия появляются в выборе станций. |
| Другие источники | Кнопки воспроизведения поддерживаемых сетевых/USB-входов; доступность зависит от ресивера и источника. |
| Таймер сна | Выключен либо 30, 60, 90 и 120 минут. |
| Настройки | IP ресивера и галочки видимых источников с сохранением после перезапуска. |

Состояние обновляется каждые пять секунд, пока вкладка видна. Статус, конфигурация, сведения о треке, радио и списки загружаются асинхронно. Элементы **текущей папки** заранее подгружаются в фоне без кнопок страниц. Готовые строки остаются доступными, элементы DOM и положение прокрутки сохраняются. Навигация отменяет предзагрузку, устаревшие ответы отбрасываются.

Названия RDS сохраняются после двух одинаковых показаний при настроенной станции. Они привязаны к частоте и ресиверу, доступны всем браузерам и не исчезают при временном отсутствии RDS. Если имя ещё не получено, остаётся частота. Автоматического обхода всех радиостанций нет.

## Совместимость и требования

- Проверен **Yamaha RX-V575** с XML-интерфейсом `/YamahaRemoteControl/ctrl`. Другие модели с этим протоколом могут работать, но не проверены; приложение не использует MusicCast API.
- Docker с Docker Compose либо Docker Desktop на Windows/macOS.
- Docker-хост должен иметь доступ к ресиверу в LAN. Для SERVER сам **ресивер** должен видеть DLNA-сервер.
- Современный браузер; телефон в той же сети использует этот же пульт.
- Для включения по сети активируйте **Network Standby**. Желательно закрепить IP ресивера в DHCP роутера.

Диапазоны проверенного RX-V575: FM 87.50–108.00 MHz, шаг 0.05 MHz; AM 531–1611 kHz, шаг 9 kHz.

## Развёртывание в Docker

Скачайте ZIP репозитория и распакуйте либо клонируйте репозиторий GitHub:

```sh
git clone https://github.com/pilotag812/yamadeck.git
cd yamadeck
```

Скопируйте пример настроек:

```sh
# Linux / macOS
cp .env.example .env
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
```

Откройте `.env` и укажите IP своего ресивера вместо примера:

```dotenv
RECEIVER_HOST=192.168.1.100
WEB_PORT=8095
MAX_VOLUME_DB=-10
```

Соберите и запустите контейнер:

```sh
docker compose up -d --build
```

Откройте [http://localhost:8095](http://localhost:8095). На телефоне используйте `http://<IP-Docker-хоста>:8095`. Кнопка **⚙ Настройки** позволяет изменить IP ресивера и выбрать видимые источники.

На Linux и NAS с поддержкой Docker Compose используется тот же файл. Собирайте контейнер из этой папки, опубликуйте веб-порт и обеспечьте доступ хоста к ресиверу. Режим сети host не требуется. Готовый Docker-образ пока не опубликован.

### Параметры

| Переменная | Значение в поставляемых файлах | Назначение |
| --- | --- | --- |
| `RECEIVER_HOST` | `192.168.1.132` | Начальный адрес ресивера; замените для своей LAN. |
| `WEB_PORT` | `8095` | Веб-порт на Docker-хосте. |
| `MAX_VOLUME_DB` | `-10` | Максимальная громкость для команд из YamaDeck. |

IP, сохранённый в настройках, имеет **приоритет** над `RECEIVER_HOST`. Окно доступно даже без связи с ресивером; галочки источников появятся после успешного подключения.

`MAX_VOLUME_DB` принимает −80.5…+16.5 dB с шагом 0.5 dB. Ограничение относится только к веб-пульту, а не к физическому пульту и другим приложениям. Пресеты выше лимита недоступны. После изменения `.env` снова выполните `docker compose up -d`.

### Сохранение данных

Именованный том `radio-data`, подключённый к `/data`, хранит `settings.json` (IP и источники) и `radio-names.json` (названия RDS). Данные сохраняются при обновлении контейнера и обычном `docker compose down`. **Команда `docker compose down --volumes` удаляет их.** При переносе установки сохраняйте имя проекта Compose: переименование папки или проекта может подключить другой том.

## Обновление и обслуживание

После загрузки новых исходников либо `git pull` в опубликованном репозитории:

```sh
docker compose up -d --build
docker compose ps
docker compose logs --tail 50
```

Остановка с сохранением данных — `docker compose down`. Healthcheck проверяет веб-сервер, а не связь с ресивером. Ошибки подключения видны в интерфейсе; приложение автоматически повторяет запросы.

## Запуск без Docker

Используйте Python 3.13, как в контейнере. Сторонние Python-пакеты не требуются.

```sh
# Linux / macOS
RECEIVER_HOST=192.168.1.100 MAX_VOLUME_DB=-10 python server.py
```

```powershell
# Windows PowerShell
$env:RECEIVER_HOST = '192.168.1.100'
$env:MAX_VOLUME_DB = '-10'
python server.py
```

Адрес — [http://localhost:8080](http://localhost:8080). Переменная `PORT` меняет порт, `DATA_DIR` — папку данных (по умолчанию `data/` рядом с `server.py`). При прямом запуске `.env` не загружается: его читает Compose при развёртывании в Docker.

## Проверки

```sh
python -m unittest discover -s tests -v
node tests/test_frontend.cjs
```

Тесты используют имитатор ресивера и записанные XML; команды реальному устройству не отправляются. Проверка frontend покрывает фоновую загрузку, доступность строк, сохранение DOM и устаревшие ответы. Node.js нужен только для проверки frontend, для запуска он не требуется.

## Решение проблем

| Проблема | Что проверить |
| --- | --- |
| Нет связи с ресивером | IP в настройках, доступ по LAN, Network Standby. |
| Телефон не открывает страницу | IP Docker-хоста, порт, брандмауэр, подключение к LAN. |
| Нет серверов DLNA | Сервер должен быть виден ресиверу: обнаружение, общая медиатека, изоляция сети. |
| DSP или тембр недоступны | При необходимости выключите Straight/Direct; Direct обходит тембр. |
| В выборе радио только частоты | Дождитесь RDS и двух одинаковых показаний; некоторые станции не передают имя. |
| Старый IP после изменения `.env` | Измените настройки: сохранённый адрес имеет приоритет. |

## Безопасность и публикация

Приложение рассчитано на **доверенную домашнюю сеть**. Встроенных авторизации и HTTPS нет. Не публикуйте порт напрямую в интернете; для удалённого доступа используйте VPN. Специальные JSON-заголовки и проверки источника запроса не заменяют авторизацию.

YamaDeck — независимый проект, не связанный с Yamaha. Репозиторий: [pilotag812/yamadeck](https://github.com/pilotag812/yamadeck). На GitHub размещаются исходники; пульт работает на вашем Docker-хосте, а не в GitHub Pages. Лицензия пока не выбрана; определите её перед публичным распространением.
